# Desktop Organizer(目前更新到version0.2）

> **AI-powered desktop file sorter** 基于 DeepSeek 的智能桌面收纳工具
## 简介|Introduction

桌面文件总是杂乱无章？**Desktop Organizer** 可以帮你：
- 扫描 Windows 桌面所有文件
- 利用 **DeepSeek 大模型** 智能分析文件名和扩展名
- 将普通文件（文档、图片、视频、压缩包等）自动归档到 **层级目录**
- **绝对不动** 文件夹、软件、快捷方式和受保护文件（标注为别碰即可）

>目前为vibecoding10分钟+修改测试10分钟做出来的 **Demo 版本**，单纯是因为懒得收拾电脑桌面+Deepseek api-key用不完了。如果我想起来了，后续可能会继续完善。欢迎试用和反馈！
